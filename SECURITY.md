# Reporting a security concern

Please do not post clipboard contents, files, pairing information, or other
private details in a public GitHub issue.

Use [PebblePaste's feedback page](https://handypebble.com/pebblepaste-feedback/).
Include the app version, Windows version, and a short description. Do not
attach private files or clipboard contents. If more confidential information
is needed, wait for a reply before sharing it.

Use PebblePaste only on a private network with PCs you trust. Compare all six
pairing digits, pause sharing before copying private items, and keep Windows
security enabled.
