# PebblePaste release notes

## 0.2.1 — October 2, 2026

- Start pasting a copied file selection in File Explorer before every file
  arrives on the receiving PC.
- Use the Windows copy dialog for progress, speed, cancellation, and naming
  conflicts.
- Copy files, folders, and mixed selections without deleting the originals.

Keep both PCs connected and sharing until copying finishes. Interrupted copies
restart from the beginning; files already created at the destination may remain.
See the official product page for supported platforms and current limits.
