# PebblePaste release notes

## Windows 0.3.2 and Intel Mac 0.2.3 — November 1, 2026

- Use one keyboard and mouse across Windows PCs by moving the pointer across the screen edge.
- Choose Portal, Ripple, or Particle Jump screen-crossing effects, adjust their intensity, or turn them off. Preview effects locally without a second computer.
- Copy text, links, files, and folders between directly paired Windows PCs and Intel Macs. The developer confirmed Windows 0.3.2 and Intel Mac 0.2.3 working together in their own setup.
- Windows 0.3.2 improves control recovery when input traffic backs up.
- Download both current packages directly from GitHub without an account.

Keyboard and mouse sharing and crossing effects are Windows-only. The two
platforms intentionally have different version numbers. This upload republishes
the existing packages, not a new build. Older notes below remain as history;
only current packages are offered in the release downloads.

[Downloads and installation instructions](https://github.com/adrovo-max/PebblePaste/releases/tag/v0.3.2).

## 0.2.1 — October 2, 2026

- Start pasting a copied file selection in File Explorer before every file
  arrives on the receiving PC.
- Use the Windows copy dialog for progress, speed, cancellation, and naming
  conflicts.
- Copy files, folders, and mixed selections without deleting the originals.

Keep both PCs connected and sharing until copying finishes. Interrupted copies
restart from the beginning; files already created at the destination may remain.
See the official product page for supported platforms and current limits.
